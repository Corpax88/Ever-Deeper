The native exact candidate1 reproduction consumed a real worm, opened the menu and started New Game. The new seed retained 19.983 seconds of the old expedition's temporary mining-speed boost. `CompanionInterface` only cleared it while `game_started` was false, a condition not reached during an in-place New Game. Reused companion nodes also retained task, cooldown and counter fields.

New Game now explicitly resets the companion interface and all six loaded world companions. Temporary boost, held gestures, work tasks, cooldowns, route hints, diagnostic counters and loose worms are cleared; each companion rejoins the newly placed hero on its next active update. Ordinary world travel and pause retain the existing boost/cooldown behavior. RunState, achievement records, audio preferences and art are unchanged by this reset API.
