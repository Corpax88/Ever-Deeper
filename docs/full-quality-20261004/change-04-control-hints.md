# Change 04: current and resumable control hints

The touch tutorial now shows the actual Skills knot/caption used by the HUD. Opening a menu before the tutorial finishes no longer permanently marks the tutorial as read; the existing Continue path shows it again. A prior fade is cancelled when reopening so it cannot hide the new hint sequence. Previously completed tutorial preferences are preserved.

Validate first10seconds, menu interruption at1second and during fade, Continue/reopen, and existing seen preference. Controls replay from Settings remains a separate UX improvement.
