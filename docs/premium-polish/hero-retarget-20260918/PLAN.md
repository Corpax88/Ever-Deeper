# Bounded stock-animation compatibility trial

Mats authorized this trial after the 18 September discussion about quota cost.
Keep the approved v28 hero, the existing saved game source, and the FPS pause.
This study does not adopt another character or replace production sprites.

## Decision to resolve

Can one openly licensed animation set provide useful motion on the actual v28
rig, with substantially less custom work than the existing procedural route?
Inspect the real rigs and the available free clips before selecting a motion.
Start with Quaternius Universal Animation Library Standard, CC0, obtained from
the author's official download. Do not buy or use gated Source/Pro assets.

## Evidence and sequence

1. Restore and verify source commit, original Blender files and runtime tools.
2. Inspect rig hierarchy/rest axes and the actual animation inventory. Record
   what transfers directly, what needs a mapping, and missing actions.
3. On a copy, preview one tool/view and a short idle/walk/strike/stop sequence.
   Use low-cost previews before a new sprite bank. Preserve existing proven
   input, hit timing and cancellation behavior.
4. Inspect grip, clear impact, believable weight, limb shape and smooth stops.
   Use one independent critic on actual captured motion at this decision point.
5. Expand only after useful motion is demonstrated. Save the trial and concrete
   decision, including any limitations, instead of labelling it production-ready.

## User's revised iteration rule

One bounded attempt per plan, not a fixed maximum number of attempts.
After a failed attempt: record what worked and failed, distinguish measured
causes from hypotheses, write specific changes and pass criteria, then run the
revised plan once. Retain successful work. Do not repeat unchanged expensive
tests or render a full atlas merely to accumulate green checks.

The current saved baseline remains on codex/hero-animation-dev13-20260918.
Private Blender originals, user saves and authentication data remain outside Git.
