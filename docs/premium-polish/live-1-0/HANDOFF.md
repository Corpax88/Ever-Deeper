# Ever-Deeper — LIVE1.0.0 er publisert

23. september 2026. Mats ba uttrykkelig om å flytte den pussede DEV15.5-versjonen til LIVE uten DEV-knapp. **LIVE1.0.0 er publisert på https://corpax88.github.io/Ever-Deeper/.** Produksjonsbygget har ingen utviklermeny eller render-probe-ressurs. Det beholder den godkjente helten, native animasjoner og verktøy, større HUD-ikoner, Skills med XP-barer og sølvoverskrifter, fjernet Wayfarer og flyttet Copper Ridge. DEV15.5 og historisk Worn er bevart uendret på sine URL-er.

Kanonisk kilde: Corpax88/Ever-Deeper, gren codex/live-1-0-20260923. Eksakt eksportcommit `28667f9796d386472f021771ed9336223efe0a48`. Main holder publiseringsbevis. Produksjonsversjon1.0.0 i project.godot; native_worn aktivert i begge buildsmaker, player_visual sin DEV-begrensning fjernet, de tre mining-presentasjonsvaktene følger native_worn-innstillingen, og produksjonseksporten inkluderer de samme native datafilene. Én kontekst-synkronisering i _dev_jump_surface retter QA/DEV-teleport til samme lagrede miningpunkt. Vanlig resume-logikk er ikke endret. Gameplay/balanse/lagringsformat er ellers uendret fra godkjent DEV15.5.

Test-run 35858775472 besto seks eksporterte kjernekontroller (input,overhaul,touch,layout,build-flavor,one-point-zero-migration),26 Skills-kontroller og 69 faktiske Chromium/Metal-kontroller. Produksjonsflagg, fravær av DEV-meny/ressurser og faktisk save-sti er observert i det eksporterte spillet. Checkpoint, reload og Continue bevarte seed, gull og miningXP. Vanlig Mac WebKit oppstart, ny runde og lagret meny besto uten QA-argumenter. Ti sluttbilder er inspisert og uavhengig akseptert (kode9/10, avgrenset visuell vurdering8/10). Fysisk iPhone er fortsatt ikke verifisert.

Lagringsidentitet er beholdt: user://ever_deeper_run_v3.sav under Ever Deeper- Godot Production Port. LIVE og DEV har separate lagringer; DEV-fremgang kopieres ikke automatisk til LIVE. Ingen nye migreringsregler eller sletting av brukersaves er lagt til. Tester på dagens format er ikke bevis for automatisk import av eldre unsupported LIVE-formater.
