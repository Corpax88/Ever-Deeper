A separate dynamic terrain light viewport reduced main-viewport time but added its own GPU cost. Deep at1696x780 measured about36FPS, rootGPU13.2ms plus fieldGPU8.3ms. This regressed the existing path. The experimental runtime and shader were removed; no quality reduction was accepted.

## Native animation pilot

115 genuine Worn/right Blender frames were rendered from the approved v28 model with the real tool, corrected grip frame, full-body anticipation/contact/recovery and two pose bridges. Export fingerprints now include the native gear, profile JSON and source manifest, and pose sampling follows the actual camera.

The independent numeric critic checked55,616 full poses,139,876 arbitrary blends,480 pickaxe-rig samples and1,485 normalized drill-rig samples. No remaining unreachable IK was found; final hand errors were below0.00000050. Camera-correct foot compensation removes systematic planted-foot sliding in the continuous sample (up toabout1.2px remaining sampling error at50/60FPS).

This is not approved production motion. The120px/10%contact trial gives35ms support per foot at340px/s and is too light for the character; the fixed pose bridges preserve position but stop velocity, lift both feet, and the drill needs forward rotor coasting rather than interpolation back to zero. The contact metadata and quaternion precision defects were corrected after the first image set. Native originals/photos remain outside public source.
