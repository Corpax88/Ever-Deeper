RunState owns a single schema-3 document and one disk format. Public
`serialize()` / `deserialize()` still exchange dictionaries. Old, unversioned,
future, incomplete and invalidly typed documents are rejected before changing
live state or canceling commerce transactions. Old saves may be reset: the
user explicitly approved this. Schema 3 has not been deployed.

`scripts/state/run_save_codec.gd` stores:

| Offset | Value |
|---:|---|
| 0 | Four-byte magic `EVDR` (`0x52445645`, little endian) |
| 4 | Four-byte schema version, currently `3` |
| 8 | Four-byte payload length |
| 12 | SHA-256 digest, 32 bytes |
| 44 | Typed Variant dictionary payload |

Maximum payload size is 64 MiB. Magic/version, bounded exact length and SHA-256
are checked before decoding. `decode_var_size(0, false)` also rejects trailing
bytes inside the payload; `bytes_to_var` then reads the dictionary without
constructing Objects. Encoding uses `var_to_bytes`, never the `_with_objects`
API. The writer no longer decodes its own just-encoded payload merely to check
it again. See the official [object-disabled decoding API](https://docs.godotengine.org/en/stable/classes/class_%40globalscope.html#class-globalscope-method-bytes-to-var)
and [native size validation](https://docs.godotengine.org/en/stable/classes/class_packedbytearray.html#class-packedbytearray-method-decode-var-size).

Production uses `user://ever_deeper_run_v3.sav`; DEV and DEV QA use distinct
`ever_deeper_dev_run_v3.sav` / `ever_deeper_dev_qa_run_v3.sav` paths. There is no
JSON fallback or parallel old/new disk implementation.

RunState is the single atomic-generation owner. It writes and flushes `.tmp`,
compares the read-back bytes exactly, rotates a validated primary to `.bak`,
then renames the temporary generation into place. The previous valid generation
is retained after success. A corrupt primary cannot replace a good recovery
backup. Temporary files are never loaded as committed saves. Failed writes
report an error and retain the committed generation.

Typed storage preserves integers above 2^53 and fractional values. RunState's
integer sanitizers now keep actual integers as integers rather than converting
them through floating point first.
