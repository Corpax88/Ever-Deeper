## Important known gate

The latest physical iPhone result is **52.1 FPS with normal pet lighting**, 60 with
pet lights off. This build is not certified at 60 FPS. Rendering work investigates hub
light receivers while preserving lights, shadows, artwork and DPR. A small compensated
trim of transparent texture margins is retained for DEV device testing: native gains
of 3.3–8.5% included 2.7–5.8% control drift, with sparse raster rounding at most 2/255.
It is not a verified phone performance fix.
Only inspected final-package visual/gameplay evidence permits a DEV test publication.
Physical iPhone acceptance remains necessary before calling this an approved 1.0.
