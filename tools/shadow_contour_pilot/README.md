# Exact shadow-boundary study

Opt-in only. Production remains source c8906f1, documentation checkpoint 9502675.
The candidate copies the existing footprint query, emitter exclusions, terrain
query, signature invalidation and process priority. Only its final rectangular
shadow shapes are converted into closed tile-union boundary loops.

All 512 binary 3×3 topologies and 167,936 air-origin rays pass an independent
boundary/intersection comparison. This is geometry evidence, not rendered parity
or an FPS result. Separate loops preserve holes for edge shadows; they do not
preserve a filled SDF union. Production currently has no SDF consumer.

Keep every lamp, PCF setting, native PNG, texture import, draw order and collision
unchanged. Diagonally touching components stay separate. Loops are bounded below
16,384 vertices. The initial full-frame 1696×780 A/B/A2 must be exact before
extending the matrix or running timings. A failed restored control invalidates
the fixture; a stable control with candidate differences rejects that candidate.

Next gates: all five Deep strata, four D2 mines, damage/depletion, holes/concavities,
permanent/gated walls, maximum hero and distant Long Beam pet, same-frame motion,
stream rebasing, zoom, hide/show and re-entry. Only after exact parity: serialized
20s frozen A/B/A and independent 60s moving Deep/Ember A/B/A with movement and
mined/depleted cells in every 10s window. Measure total frame cost and rebuild
overhead, not only node/draw-count reduction. No production adoption yet.
