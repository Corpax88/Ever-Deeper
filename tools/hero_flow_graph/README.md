# Approved Flow20 integration candidate

Work in progress, not production acceptance. `flow_graph_enabled` remains false
outside the explicit actual-game capture. The approved50-frame color atlas is
copied byte-for-byte; the original cloth masks restore all five outfit colors.

The controller has finite, reversible native paths. Mining cancellation follows
the approved loop. Entry settles to exact legacy walking nodes before a full-bone
port to ready. An exit must start from the actually displayed Flow20 frame; the
stationary recovery/port route was rejected because it would slide planted feet
with the immediately moving gameplay root.

`export.py` produces57 genuine native frames for three canonical entry ports.
It preserves study21's reviewed full-bone adapters and adds a common shallow body
crouch when a planted turn otherwise extends a short leg beyond its reach.
Defaults leave the original two study21 paths unchanged.

`export_exits.py` checks every one of the50 exact mining source frames before
rendering. It uses a short airborne transfer to legacy up-walk cell12. The first
0.106s analytical attempt exceeded the existing angular-rate gate in26 paths and
rendered no images. The same native path at0.18s passes all50 checks; that supports
rendering, not visual acceptance. Twelve intervals preserve useful sampling at60Hz.
The source endpoint reuses its original rendered image, and every identical walk
endpoint reuses the first actual native render of that endpoint.

`package.py` binds the unchanged loop and masks. `package_exits.py` removes only
transparent margins, uses a consistent adjusted anchor, keeps mask/color UVs
identical and splits exit images into pages below4000px. No rendered pose is
deformed, stretched or blended at runtime.

The actual-game fixture `capture.gd` uses ordinary held mining and joystick APIs,
records all rendered frames, gameplay state, equipment and exact graph cells.
Pass `--baseline` for the unchanged renderer and `--forge=5` for the fastest Worn
cadence. Scenarios include held mining, walk entry, interruptions and equipment/
outfit changes. Numeric native gates do not replace mobile image review.

Concrete controller corrections from independent review:

- A pending impact remains presentable after a later inactive packet.
- Mining restarts survive coalesced packets between draws.
- A walk-phase handoff applies once, and retains walk24's canonical identity.
- Eligible zero-delta state packets cannot overwrite the actually shown source.
- The existing shader/cache owner continues to own outfit and equipment changes.

First actual150-frame capture completed with3hits/12damage, but exposed the last
source-identity defect above. It is not release evidence for the corrected code.
Gameplay parity, exit grounding, fastest-cadence reversal, exported-package checks
and independent image review remain mandatory before enabling ordinary gameplay.
