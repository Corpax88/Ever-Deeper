# Mole journal reactions

Ten authored, transparent PNG animation atlases generated with the built-in imagegen tool from `../mole.png` as the character reference. Original generated alpha is preserved; no generated bitmap was rescaled or composited during integration.

Each PNG contains eight sequential poses in four columns and two rows. Actual image dimensions are 1774 × 887; CompanionJournal computes rounded cell boundaries rather than assuming a power-of-two export. The wave sequence selects near-paw poses only to avoid alternating arms. All other sequences play in row order.

Common production prompt constraints: exact original mole identity and painted detail, brass headlamp helmet, olive overalls, brown satchel, cream claws and pink nose; fixed camera and consistent scale; full body within each cell; genuine transparent background; no text, grid, props or concept-sheet composition. Eight progressive animation frames, not eight alternative concepts.

Playback takes 1.54 seconds. A shuffle bag visits all ten reactions before repeating and prevents repeats across bag boundaries. Taps during playback do not queue or restart reactions. Closing or reopening restores the original portrait. Petting never changes saved resources, skills or paw points.
